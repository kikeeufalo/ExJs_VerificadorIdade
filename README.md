# Verificador de Idade em JavaScript

Exercício desenvolvido com o objetivo de criar um **verificador de idade**, utilizando **JavaScript** para interação com o usuário.

O projeto aplica conceitos de **lógica de programação**, **manipulação de dados** e **interação com a interface**, permitindo verificar informações com base na idade informada.

Este repositório representa um exercício prático de aprendizado, reforçando o uso de JavaScript em aplicações interativas.
